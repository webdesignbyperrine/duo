Joindre un projet de code

Choisis un dossier entier ou clone un dépôt GitHub. Les deux assistants reçoivent la même copie de lecture du code retenu et peuvent ouvrir les fichiers utiles.

Les dépendances, caches, fichiers générés et secrets détectés sont exclus. L’inventaire permet de contrôler le périmètre retenu. L’import ne lance aucun code du projet. Les assistants travaillent sur une copie de lecture. Dépôts privés : accès via la connexion GitHub disponible sur cet ordinateur.

Continuer et demander des fichiers

Les pièces et les fichiers précédents restent disponibles dans cet onglet jusqu’à la fin de la discussion. Les réponses déjà produites seront partagées avec l’assistant choisi. Les formats cochés plus haut s’appliquent aussi à cette demande.
L’interface peut être hébergée sur Vercel ; la lecture des pièces et les assistants tournent sur ton ordinateur. Les fichiers ne transitent pas par Vercel. Le texte des pièces et les analyses nécessaires à chaque étape sont transmis à OpenAI et Anthropic via leurs programmes officiels, connectés à tes abonnements. Duo ne crée aucun historique ni mémoire entre discussions. « Terminer et effacer », fermer ou actualiser cet onglet arrête la discussion et efface ses données du relais. Si le navigateur disparaît sans prévenir, une expiration de secours intervient après deux minutes sans contact. Les résultats restent disponibles tant que cet onglet reste ouvert ; télécharge-les avant de le fermer. Le dossier complet permet de télécharger les pièces d’origine, le texte fourni, les analyses, les livrables générés et la trace des transmissions. Les fournisseurs peuvent conserver leurs propres journaux. Un accord entre assistants ne constitue pas une validation humaine ou une preuve d’exactitude.
